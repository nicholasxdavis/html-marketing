# Copy spec

## Formula

> Desired outcome + short supporting line + product proof

Weak: Advanced Analytics
Better: Know what is actually working
Stronger: See what your customers do. + the real UI

Feature -> Benefit -> Outcome. Sell the outcome.

## Five-beat store set

Do not design isolated posters. Design one story.

1. **Hook** - Why should I care? Strongest benefit. Clearest category signal.
2. **Mechanism** - How does it solve it? One workflow, cropped large.
3. **Differentiator** - Why this, not the alternative?
4. **Benefit** - Secondary value. Still one idea.
5. **Trust** - Only true claims. Local, private, offline, no account.

## Length

| Slot | Limit |
|------|-------|
| Headline | 3 to 7 words |
| Support | One sentence, max ~12 words |
| Promo tile | 2 to 5 words |
| YouTube thumb | 3 to 5 words |
| PFP | No words. Mark only. |

## Forbidden

- Download now, Install now, Try now, Click here
- Emoji
- Em dashes and en dashes (use comma, period, or hyphen)
- Feature-category titles with no outcome
- Fake review scores
- Claims you cannot defend

## Tone

Professional. Direct. Specific. No slang unless the brand already uses it.
Sentence case. Imperative is fine for outcomes ("Find any file in seconds").
The store already has the install button. The creative explains why.
