# Product launch set

1. Write `BRIEF.md` (product, outcome, platform, style).
2. `npx html-marketing init <name> --non-interactive` or edit an existing project.
3. Replace Northline copy. Keep Atlas/Harbor geometry unless BRIEF names another style.
4. `npx html-marketing check && npx html-marketing render`.
5. Optional sting via `/motion-sting`. Optional social via `/social-post`.
   Look up every preset. Phosphor Regular for icons.
