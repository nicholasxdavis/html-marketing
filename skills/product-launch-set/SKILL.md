# Product launch set

1. Write `BRIEF.md` (product, outcome, platform, `style: studio`).
2. `npx html-marketing init <name> --non-interactive` or edit an existing project.
3. Replace Northline copy. Remake UI from source at native width. Do not keep Harbor geometry unless BRIEF names harbor.
4. Promo: brand-light field, white type, no UI.
5. `npx html-marketing check && npx html-marketing render`.
6. RSI on the PNGs.
7. Optional sting via `/motion-sting`. Optional social via `/social-post`.
   Look up every preset. Phosphor Regular for icons.
