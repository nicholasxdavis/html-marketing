# Social post

Install if needed: `npx html-marketing skills update social-post`

1. Confirm surface. Run `npx html-marketing sizes <platform-or-id>`.
2. Pick the named preset. Do not invent pixels.
3. Studio promo composition by default: accent-light field, white type, one idea.
4. Remade UI only if the canvas is large enough that labels stay readable.
5. Respect safe zones (stories 14% top/bottom, YouTube thumb bottom-right clear).
6. `npx html-marketing check` then `preview` then `render --preset <id>`.

Copy: 3 to 7 words. Outcome, not a caption dump.
PFPs: mark only, circle-safe, no type.
Thumbnails: huge type, one subject, no watermark in the duration corner.
