# Prompts

```bash
npx html-marketing prompts
npx html-marketing prompts atlas
npx html-marketing prompts store-set
```

| File | Use |
|------|-----|
| `store-set` | Any new listing |
| `atlas` | Default dark green field |
| `harbor` | Chrome / Mac landscape split |
| `meridian` | Light studio |
| `clay` | Matte clay device |
| `ledger` | Ink field, serious product |
| `copy` | Headlines only |
| `device` | Frame choice only |

If you need a new look, add `prompts/styles/<name>.md` first. Do not freestyle.
