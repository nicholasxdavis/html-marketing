# Prompts

```bash
npx html-marketing prompts
npx html-marketing prompts studio
npx html-marketing prompts store-set
```

| File | Use |
|------|-----|
| `studio` | Default. Card + pattern + remade UI |
| `store-set` | Any new listing |
| `rsi` | Inspect PNG, fix, re-render |
| `atlas` | Legacy dark green field. Off unless BRIEF says atlas |
| `harbor` | Legacy Chrome split. Off unless BRIEF says harbor |
| `meridian` | Light studio |
| `clay` | Matte clay device |
| `ledger` | Ink field, serious product |
| `copy` | Headlines only |
| `device` | Frame choice only |

If you need a new look, add `prompts/styles/<name>.md` first. Do not freestyle a split poster.
