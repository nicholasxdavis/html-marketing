# Store listing

`npx html-marketing skills update store-listing`

1. Confirm platform. `npx html-marketing sizes <platform>`. Do not invent pixels.
2. Defaults: `cws-screenshot`, `ios-6-9`, or `play-phone`. Policy: `npx html-marketing specs platforms`.
3. Paste `prompts/store-set.md` and `prompts/styles/studio.md`.
4. Five HTML frames. Same Studio card. Remake UI from source. Copy from `npx html-marketing specs copy`.
5. Phosphor Regular inside product UI if needed.
6. `npx html-marketing check` then `preview` then `render`.
7. Open the PNGs. RSI (`prompts/rsi.md`) until the two-second test passes.

Never write Download now / Install now / Try now.
Never paste a live screenshot into a fake browser.
