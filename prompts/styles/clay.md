# STYLE: Clay

Matte clay device. Warm gray field. Soft shadow. No chrome shine.

## Use when

Wellness, analog-feeling products, brands that should not look like SaaS.

## Tokens

```css
.field-clay
--bezel: #C8C2B6
```

Device class: `.phone.clay` only.

## Composition

Same geometry as Atlas or Harbor. Only the materials change.
No island shine. No glossy highlight.

## Forbidden

Black bezels, colored clay, 3D perspective unless the whole set uses the same tilt.
