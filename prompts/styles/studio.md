# STYLE: Studio

Default for every new listing.

Quiet card. Remade product UI. Icon pattern. Centered.

## Use when

Chrome extensions, utilities, web apps, mobile, anything that used to get Harbor or Atlas.

## Tokens

```css
--field: dark wash from brand
--accent: brand primary
--accent-light: brand light (promo background)
--card: #f3f0f6
--type: #0e0e10
```

Link `shared/studio.css`. Override tokens on the page.

## Composition

- Screenshot / marquee: Field + Card + Head + Proof + Foot
- Promo: accent-light field, white type, logo, no proof UI
- Proof width locked. No CSS scale
- Pattern: product or partner icon, opacity 0.07

## Type

Headline 800, 3 to 7 words, unique to the product.
Foot max 12 words.

## Forbidden

Left caption column. Overflowing browser. Pasted live screenshots. Chat sidebars. Stats HUDs. Site headers. Em dashes. Stretched popups. UI on promo tiles.
