# RSI loop

Required after every first render.

1. Open each exported PNG.
2. Write a short bug list. Concrete only (stretched popup, clipped row, slogan that does not describe the product, leftover tooltip, dead space, uncentered card).
3. Fix those bugs in HTML/CSS. Do not redesign from scratch unless the composition is still Harbor.
4. Re-render.
5. Repeat. Stop when the two-second test passes or after 4 passes with shrinking issues.

Never declare done while:

- Product UI is scaled or stretched
- A live screenshot still contains site header or chat
- Promo contains a remade popup
- Copy could fit a different product
- Labels are truncated
