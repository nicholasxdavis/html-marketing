# COPY

Write store captions. Do not design.

## Formula

Headline = outcome, 3 to 7 words.
Support = how, max 12 words.
Proof = the device UI, not more text.

## Beats

1. Hook: why should I care
2. Mechanism: how it works
3. Differentiator: why this wins
4. Benefit: what else I get
5. Trust: only a claim that is true

## Voice

Direct. Specific. Present tense. No slogans. No hype adjectives (ultimate, revolutionary, magic).
No Download / Install / Try now.
No emojis. No em dashes.

## Replace these

| Weak | Stronger |
|------|----------|
| Advanced search | Find any tab in seconds |
| Powerful dashboard | See what changed today |
| Smart notifications | Only the alerts that matter |
| Seamless sync | Your library, every device |
| Privacy focused | Local by default |

## Output format

Return five pairs:

```text
01 HOOK
headline:
support:
02 MECHANISM
headline:
support:
...
```
