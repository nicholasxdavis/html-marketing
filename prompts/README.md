# Prompt library

These files are the design. You do not think up a look.

## How to use

1. Look up the canvas: `html-marketing sizes <platform-or-id>`.
2. Run `html-marketing prompts` and pick a file.
3. Paste that file at the top of the agent turn.
4. Add only product facts: name, outcome, 5 beat headlines, inner UI truth.
5. Keep the layout class, tokens, and device style named in the prompt.
6. Phosphor Regular if an icon is needed. `html-marketing specs icons`.
7. If the result drifts, paste the same prompt again. Do not negotiate a new aesthetic.

## Why this works

Strong prompts are recipes, not moods.

- Same content, swapped tokens. That is how a style explorer works.
- Numbers beat adjectives. "Headline 64px, 3-7 words" beats "make it punchy".
- A forbidden list is as important as the allowed list.
- One style per set. Never mix Atlas with Clay inside five frames.
